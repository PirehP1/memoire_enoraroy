## L'usage de l'IA comme assistant de protocole

Ce dossier regroupe les éléments accompagnants la lecture de la section de notre Chapitre 3, intitulée "l'IA comme assistant de protocole". A ce titre, nous proposons dans ce dossier deux éléments : un prompt et le script associé comme réponse. Les enjeux et discussions autour de l'usage de l'IA sont discutés dans le fichier du mémoire.

Le fichier `Exemple_prompt_BERT.md` présente un exemple de prompt utilisé comme une première étape dans ma conception du workflow sur BERTopic, outil inutilisé dans le cadre universitaire. Ce prompt a été adressé à Claude Sonnet 4.6.

Le fichier `Sortie_LLM.py` correspond à la sortie du modèle, dénuée de la prose l'accompagnant, que je reproduis ici : "Le script ne nécessite pas de skill spécifique — je peux le construire directement. Voici le pipeline complet :". Je n'ai rien modifié du script, pour donner à voir une sortie brute du LLM.
