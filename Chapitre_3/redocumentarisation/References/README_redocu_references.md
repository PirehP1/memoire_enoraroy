## Redocumentarisation des références

L'objectif est d'augmenter les métadonnées et les données associées aux références bibliographiques à partir des informations déjà disponibles dans les corpus collectés.

### Contraintes juridiques

Pour des raisons juridiques et légales, l'intégralité des données sources ne peut pas être redistribuée ici : pour JSTOR, je mets à disposition un extrait des fichiers envoyés. Pour les données envoyées par les personnes contactées, rien n'est redistribué sans leur accord.

Les éléments documentés dans ce dépôt concernent donc :

* les opérations réalisées en interne sur les fichiers `jsonl` fournis par JSTOR ;
* les procédures de demande de données effectuées par courriel ou via les formulaires de contact des bases de données ;
* les enrichissements réalisés à partir des DOI ;
* les enrichissements produits directement à partir des données elles-mêmes, notamment par détection automatique de langue à partir des titres de publication.

### Note sur l'importance de l'enrichissement par DOI

Les opérations d'enrichissement les plus importantes sont réalisées sur les références disposant d'un DOI, d'où son usage massif dans nos protocoles. Il existe cependant des cas où certains DOI fournis par des catalogues externes (notamment WorldCat) sont erronés : le DOI peut respecter un format valide tout en ne renvoyant vers aucune ressource fonctionnelle. Ces cas nécessitent une vérification manuelle supplémentaire.
