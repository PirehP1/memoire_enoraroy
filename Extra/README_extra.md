# Quelques éléments supplémentaires

Ayant passé du temps (beaucoup de temps) sur les documents dont je propose une analyse dans mon mémoire, je souhaitais aussi donner à voir quelques pistes que j'avais pu explorer, mais au final laisser de côté pour la suite du travail. Sans prétendre à de réelles pistes de recherche, il s'agit, pour moi, de regrouper ici des protocoles exploratoires qui auraient pu devenir par la suite des pistes de recherche, donnant aussi à voir les possibles avec les données manipulées.
Il s'agit aussi de partager mon retour d'expérience, même sur les éventuels projets non aboutis : restituer, pour une intuition, ce qui a (et n'a pas) fonctionné.
