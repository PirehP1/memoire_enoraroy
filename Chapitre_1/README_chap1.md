# README du Chapitre 1

## Présentation

Ce dossier ne regroupe pas de scripts python, puisque le chapitre 1 de mon mémoire est une introduction méthodologique. Toutefois, je tiens à proposer le corpus Europresse utilisé pour générer le nuage de mots de l'introduction de mon mémoire -- d'où ce dossier. La conversion, d'Europresse à Iramuteq (logiciel utilisé pour traiter les données textuelles recueillies) a été réalisé à l'aide de l'inferace no-code proposée sur ce [site](https://europresse-to-iramuteq.streamlit.app/), créé par [Stéphane Meurisse](https://github.com/stephane1109).

## Prérequis

- Iramuteq, disponible au téléchargement en cliquant [ici](https://pratinaud.gitpages.huma-num.fr/iramuteq-website/category/installation.html)
- un abonnement [Europresse](https://www.europresse.com/) (pour ma part, permis par l'abonnement de mon Université, Paris 1 Panthéon-Sorbonne)
