# Mémoire de recherche — Analyse bibliométrique de l'historiographie des "barbares"

## Présentation

Ce dépôt GitHub contient les scripts, ressources méthodologiques et résultats produits dans le cadre de mon mémoire de recherche universitaire portant sur une analyse bibliométrique de l'historiographie des "barbares" publiée entre 1975 et 2025.

Le projet va de la récupération des données sur Worldcat à leur traitement lexicométrique, en mobilisant des méthodes d'analyses de données variées.

# Organisation du dépôt

Le dépôt est structuré selon une logique de documentation scientifique, de traçabilité méthodologique et de reproductibilité des analyses. Les dossiers sont organisés au fil de la progression du mémoire et accompagnent la lecture des différents chapitres. Chaque chapitre peut ainsi contenir, selon les besoins de la démonstration :

- des scripts Python ;
- des données ;
- des fichiers d’analyse ;
- des visualisations ;
- des résultats intermédiaires ;
- des outputs statistiques ou computationnels ;
- des ressources documentaires mobilisées dans la recherche.
