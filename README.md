# Mémoire de recherche — Analyse bibliométrique de l'historiographie des "barbares"

## Présentation

Ce dépôt GitHub contient les scripts, ressources méthodologiques et résultats produits dans le cadre de mon mémoire de recherche universitaire portant sur une analyse bibliométrique de l'historiographie des "barbares" publiée entre 1975 et 2025.

Le projet va de la récupération des données sur Worldcat à leur traitement lexicométrique, en mobilisant des méthodes d'analyses de données variées.

# Organisation du dépôt

Le dépôt est structuré selon une logique de documentation scientifique, de traçabilité méthodologique et de reproductibilité des analyses. Les dossiers sont organisés au fil de la progression du mémoire et accompagnent la lecture des différents chapitres. Chaque chapitre peut ainsi contenir, selon les besoins de la démonstration :

- des scripts Python ;
- des données ;
- des fichiers d’analyse ;
- des visualisations ;
- des résultats intermédiaires ;
- des outputs statistiques ou computationnels ;
- des ressources documentaires mobilisées dans la recherche.

## Note sur l'usage de l'IA dans ce protocole

Par souci de transparence méthodologique, je tiens à signaler que les scripts de ce dépôt ont été développés avec l'assistance de modèles de langage (LLM), principalement Claude et Gemini, utilisé comme assistant de protocole et aide au débogage. L'usage des LLM m'a permis de traduire mes intentions et étapes de traitement sur le plan de la méthode avec des programmes pour les mettre en oeuvre. En ce sens, ce n'est pas un substitut à la conception du protocole puisque j'ai défini les étapes de traitmement et les choix d'architecture des scripts. L'usage de l'IA pour imputer de la donnée (notamment le genre des auteurs) est systématiquement signalé.

Mes interactions avec les LLM se sont limitées à l'interface textuelle (chatbot), sans recours aux API payantes ni à des fonctionnalités multimédia. Aucun investissement financier n'a été engagé pour les LLMs dans ce projet. Une réflexion plus développée sur les effets cognitifs de cet usage, les biais des modèles, les enjeux éthiques et écologiques, ainsi qu'une discussion sur le prompt engineering comme mode de raisonnement, figure dans le mémoire associé à ce projet.
